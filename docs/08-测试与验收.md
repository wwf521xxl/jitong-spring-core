## 2. 运行

```bash
cd springboot-core
./mvnw test
```

测试使用 H2 内存库（`MODE=PostgreSQL`）+ Flyway + 演示种子数据，不连接任何生产库。

## 3. 覆盖场景

### 状态机

- OPEN → JOIN → OPEN；
- OPEN → BEGIN_SETTLE → SETTLING；
- SETTLING → SETTLED → CLOSED；
- SETTLING → REOPEN → OPEN；
- CLOSED / CANCELLED 拒绝所有迁移；
- 非法迁移抛异常。

### 平分

- 100 / 3 = `[33.333, 33.333, 33.334]`，总和 100；
- 48.5 / 2 = `[24.250, 24.250]`；
- 0 人返回空；
- 0 数量仍生成每人 0.000。

### 认证

- 正确工号/PIN 登录；
- 错误 PIN 返回 401 `bad_credentials`；
- 无 Cookie 访问 bootstrap 返回 401；
- Bearer Access Token 可认证；
- Cookie Refresh 可认证；
- 退出后旧 Cookie/Bearer 都失效；
- 改密后当前设备自动续期，旧密码失效，新密码可登录；
- 生产模式空库启动只创建管理员，不写入演示订单；
- 历史 PIN 哈希可直接校验。

### 业务

- 管理员建单 403；
- 排版人员建单成功，产线由单位推断；
- 自动报工第 1/2 道 → 第 3 道开组；
- 第二人加入；
- 结束合报按 2 人平分，生成 `source=group` 记录；
- 状态事件 5 条，最后一条到 CLOSED；
- 幂等键重复返回同一条记录；
- 相同数量再次提交 409 `duplicate`；
- `forceDuplicate=true` 可绕过；
- 上游未完成报下一道返回 400 `upstream_empty`；
- 完成订单自动结束 OPEN 组，并检查每道工序；
- 管理员授予建单权限后普通员工可建单。

## 4. 手工验收清单

### 启动

```bash
cd springboot-core
./mvnw spring-boot:run
```

- [ ] `http://127.0.0.1:8080/api/health` 返回 `ok=true`；
- [ ] `http://127.0.0.1:8080/` 显示登录页；
- [ ] `http://127.0.0.1:8080/api/docs` 可打开；
- [ ] 登录 `7 / 123456` 成功，刷新后仍登录；
- [ ] 登录 `admin / Admin@123456` 成功。

### 核心流程

- [ ] E007 新建 `m²` 订单；
- [ ] 自动报工第 1、2 道；
- [ ] 第 3 道出现合报组；
- [ ] E009 登录并加入合报；
- [ ] admin 结束合报，两人各 5 m²；
- [ ] 报工记录来源为 `group`；
- [ ] 订单进度正确；
- [ ] 待审批冲销可同意/驳回；
- [ ] 管理员不能建单；
- [ ] 普通员工不能进管理接口（403）；
- [ ] 退出后回到登录页。

### 数据

- [ ] 清空生产数据前生成 `data/backups/*.json`；
- [ ] 作废订单不物理删除；
- [ ] 审计日志有记录；
- [ ] 历史 PIN 哈希可登录（升级后验证）。

## 5. 断言示例

```java
mockMvc.perform(post("/api/admin/jobs/{jobId}/groups/3/close", jobId)
        .cookie(admin)
        .contentType(MediaType.APPLICATION_JSON)
        .content(json(Map.of("reason", "测试结束"))))
    .andExpect(status().isOk())
    .andExpect(jsonPath("$.job.steps[2].group.status").value("closed"))
    .andExpect(jsonPath("$.job.steps[2].group.memberCount").value(2))
    .andExpect(jsonPath("$.job.steps[2].group.perQty").value(5.0));
```

## 6. CI

```yaml
name: ci
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: springboot-core
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '21'
          cache: maven
      - run: chmod +x mvnw
      - run: ./mvnw -B verify
```
